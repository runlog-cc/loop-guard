# RunLog LoopGuard TypeScript 0.1.0

Local circuit breaker SDK for Node.js 20+, distributed as compiled CommonJS with
TypeScript declarations and no runtime dependencies. No hosted telemetry or paid
service is provisioned by this package. Bundled prices are reference estimates.

```sh
npm install ./runlog-loopguard-0.1.0.tgz
```

```js
const { CircuitBreaker } = require('@runlog/loopguard');
```

Build with `npm ci && npm run build`; test with Bun using `bun test`.
